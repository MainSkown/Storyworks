# Changelog

## 1.0.0

First release.

- Three project kinds: book, screenplay, game script.
- Book: manuscript editor with stable block IDs, timelines and custom calendar, rules, codex with relationships, states and knowledge, consistency checks, PDF/DOCX export with appendices, Markdown/plain-text import.
- Screenplay: element editor, scene numbers, page count, PDF/Word/Fountain export, Fountain import and paste.
- Game script: speaker lines with IDs, variables, branching conversations with conditions, story map, routes, game document (overview, mechanics, glossary), game checks, game JSON/CSV and document export.
- Snapshots and automatic backups, search and quick switcher, writing goals and stats, spellcheck (English, Polish), crash recovery, local diagnostics log.
- Light and dark themes, rebindable shortcuts, keyboard-operable UI, guided tour per project kind, bundled sample book, screenplay and game script. UI in English and Polish.

Known limits: installers are not code-signed; some accessibility items are deferred (see docs/review/a11y-m11b.md); a 300-node conversation canvas paints in about 330 ms.
