# Bundled spellcheck dictionaries

Shipped read-only with the app. Data files copied unchanged from the npm packages built by
[wooorm/dictionaries](https://github.com/wooorm/dictionaries); each folder keeps its own `LICENSE.txt`.

## English (`en/`) — dictionary-en 4.0.0
en_US Hunspell dictionary from SCOWL (Kevin Atkinson), affix file derived from Geoff Kuenning's Ispell.

notices are kept; the full text is in `en/LICENSE.txt`.
