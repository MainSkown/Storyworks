# Accessibility audit, M11b (script canvases and game document)

Scope: Welcome sample chooser, conversation canvas and list, story-map canvas and list, play-through panel, game document (Overview, Mechanics, Glossary, link picker, category dialog), Variables panel, screenplay editor toolbar and element keys. Both themes, browser build (`yarn dev`, Playwright against localhost:1420), keyboard only. Method as in [M11a](a11y-m11a.md); no screenshots.

Guards: `src/a11y.templates.test.ts` scans every `src/**/*.vue` (new test pins that the script and game components are in the scan; no real violations found). `src/styles/tokens.contrast.test.ts` gains a check that `--section-gamedoc`, `--section-checks` and `--tag-problem` (used as text) meet 4.5:1 on every surface, both themes (story map colour was already covered). New unit test: Escape then Tab leaves the screenplay editor.
