# Accessibility audit, M11a (Book projects)

Scope: all Book pages (Welcome, Write, Timelines, Rules, Codex incl. relationships/knowledge, Checks, Stats, History, Export, Settings), both themes, browser build, keyboard only. Script, conversation and story-map canvases wait for M11b.

Guards added: `src/a11y.templates.test.ts` (unnamed icon buttons, unlabelled fields, clickable static elements across `src/**/*.vue`), extended `src/styles/tokens.contrast.test.ts` (text, status, marker and spell colours, selected background; light and dark).
